How To Use RythaGelathi

Four simple steps — works on mobile, no app install required, results delivered in Kannada.

1

📍 Fill Your Farm Details

Select district, enter land size, current temperature, humidity, rainfall, soil pH, N-P-K values, and input budget. All fields available on the Crop Advisory tab.

💡 Use your Soil Health Card for accurate N, P, K values. Ask your KVK officer if needed.
2

🤖 Click "Get AI Advisory"

CrewAI runs all 4 agents in sequence: crop ML model, live mandi prices, 7-day weather forecast, soil NPK check. Processing typically takes 10–20 seconds.

⏱️ Speed depends on Groq + OWM API response time. 🌐 Internet required.
3

📊 Review Structured Results

You get: top 3 crops, profit estimate per crop, weather flag (GREEN/AMBER/RED), soil deficiency alerts, SHAP explainability reasons, and a full Kannada summary.

📋 Click "Copy JSON" to share results directly with your field advisor or extension officer.
4

🔄 Re-Run Weekly During Sowing

Mandi prices and weather data update daily. Re-run during your sowing window for the most current district-level recommendation.

🌱 Your NPK and pH values rarely change — save them for next run.

⚙️ Required API Keys (.env)

GROQ_API_KEY LLaMA 3.3 70B via Groq — agent reasoning engine
OPENWEATHER_API_KEY 7-day forecast per district (1000 free/day)
BHASHINI_API_KEY Government of India Kannada translation pipeline
AGMARKNET_API_KEY Optional — static JSON fallback included in repo
🚀 Quick Start
$ git clone https://github.com/Yashaswini-V21/Rytha_Gelathi.git
$ pip install -r requirements.txt
$ cp .env.example .env # fill in your API keys
$ python api/server.py
# Open http://127.0.0.1:8000 in your browser
