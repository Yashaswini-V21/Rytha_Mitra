How It Works

From farm data to Kannada advice in 4 steps

A farmer fills 10 fields on mobile. Our 4-agent AI pipeline does the rest — in 10–20 seconds.

01

Farmer enters field conditions

District, land size, current temperature, humidity, rainfall, soil pH, N-P-K values, and input budget. Takes under 2 minutes on any mobile browser — no app install.

frontend/core.html
02

4 AI agents analyse in parallel

CropAdvisor runs Random Forest + SHAP. MarketAnalyst fetches live Agmarknet mandi prices. WeatherIntel gets 7-day OWM forecast. SoilExpert checks Karnataka Soil Health Card NPK.

crew/krishi_crew.py · tools/market_price_tool.py
03

Results structured as clean JSON

top_crop, profit_estimate, weather_flag (GREEN/AMBER/RED), soil_alerts, SHAP reasons. Every single field filled — no bullet-point vagueness.

api/server.py → POST /api/recommend
04

Full advisory translated to Kannada

The entire recommendation is translated to natural Kannada via Government of India's Bhashini API — so the farmer herself can read and share it on WhatsApp.

Bhashini API · en→kn · _translate_to_kannada_bhashini

AI Pipeline

4-Agent CrewAI pipeline

Four sequential specialised agents — crop model, market, weather, soil — coordinated by CrewAI with Groq LLaMA 3.3 70B.

01🌱

CropAdvisor

crop_advisor_tool

Random Forest (100 trees, max_depth=10) on N-P-K, temperature, humidity, pH, rainfall. SHAP TreeExplainer generates force_plot and top 3 reasons per crop.

→ top_crops · shap_reasons · probabilities
02📈

MarketAnalyst

AgmarknetPriceTool

Fetches live Karnataka mandi prices via Agmarknet API (3s timeout, 6hr LRU cache, static JSON fallback). Profit = yield × price − input_costs.

→ market_prices · top_crop · profit_estimate
03🌦️

WeatherIntel

weather_intel_tool

OWM Geo API → district lat/lon → 7-day one-call forecast → aggregated temp, humidity, rainfall → GREEN/AMBER/RED flag per crop based on suitability bands.

→ weather_flags (GREEN / AMBER / RED)
04🪨

SoilExpert + Bhashini

soil_expert_tool · bhashini_translate

Karnataka Soil Health Card JSON per district flags N, P, K deficiencies. Bhashini API translates the final structured advisory to natural Kannada.

→ soil_alerts · kannada_summary
